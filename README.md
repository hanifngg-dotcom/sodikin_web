# sodikin_web

Website portfolio statis yang dibuat dengan HTML, CSS, dan JavaScript.

## Fitur

- Navigasi responsif
- Mode gelap otomatis dan toggle tema
- Section tentang, proyek, dan kontak
- Form kontak yang membuka aplikasi email

## Cara menggunakan

1. Buka `index.html` di browser.
2. Gunakan tombol "Hubungi Saya" untuk mengisi formulir kontak.
3. Ubah `sodikin@example.com` di `index.html` dan `script.js` dengan alamat email Anda.
